# barishal-Blood (বরিশাল রক্ত) - Flutter Mobile Application

Official Android & iOS mobile app for **barishal-Blood**, the divisional blood donor management and emergency blood networking system.

## 🚀 Key Features in Mobile App:
- 🩸 **Instant Blood Donor Search**: Filter across all 6 districts of Barishal Division (বরিশাল, ভোলা, পটুয়াখালী, পিরোজপুর, বরগুনা, ঝালকাঠি) and all upazilas.
- 🚨 **Emergency Blood Request Feed & Direct Call**: One-tap dialing to donor/patient attendant with urgent notifications.
- 🏥 **Hospital & Blood Bank Directory**: Real-time blood units stock view and direct ambulance lines.
- 🛡️ **Secret Admin Portal**: 5-tap easter-egg on the top logo unveils the protected administrator portal.
- ⚡ **Offline Resilience & Fast Performance**: Minimal data usage designed for 2G/3G connectivity in rural delta areas.

## 📱 How to Run & Build APK:

```bash
# 1. Install dependencies
flutter pub get

# 2. Run in debug mode (Android / iOS / Chrome)
flutter run

# 3. Build Production Release APK
flutter build apk --release

# 4. Build Android App Bundle (for Google Play Store)
flutter build appbundle
```

The APK will be generated at:
`build/app/outputs/flutter-apk/app-release.apk`
